控制台 / 工具箱

工具箱是后台自用运维入口，当前 UI 通过分类和搜索工具卡片打开子模块。它集中承载 115、转存、Webhook、FNOS、Telegram、MoviePilot、TMDB 和代理配置，但每个工具的保存与风险边界不同。

截图来自 2026-08-14 本地 CineChill 管理端；敏感字段、真实地址和私有任务状态不展示。 截图会跟随 Wiki 外观开关：浅色模式显示日间截图，深色模式显示夜间截图；截图仅用于说明布局，敏感字段不作为公开文档内容。

适用场景与准备工作

  • 统一查找账号、外部服务、转存、通知和维护工具。
  • 先完成服务器 / 115 / Emby 基础配置，再打开依赖这些连接的子模块。
  • 高风险工具（定时清空、批量上传、账号监听）必须先读对应教程，并准备测试目录 / 测试媒体库。

按页面顺序操作

  1. 左侧进入“工具箱”，使用分类按钮或“搜索工具”筛选卡片。
  2. 顶部筛选按钮对应“全部、115、Forward、Telegram、Webhook、配置”，也可以使用“搜索工具”直接筛选卡片；当前卡片包括扫码获取115CK、115定时清空、网盘资源秒传、资源转存、Forward模块、Webhook、飞牛论坛签到、Telegram监听、MoviePilot、代理配置和TMDB配置。
  3. 打开卡片后先读取当前状态；填写字段后优先点击测试 / 校验，再保存。
  4. 返回业务页面做一次单条、单目录、单任务验证，确认成功后再启用 Cron、监听或批量。
  5. 遇到异常先停用当前工具，记录错误提示和系统运行日志，再进入对应教程排查。

工具分类与字段边界

  • 115：扫码获取 CK、115 定时清空、网盘资源秒传；CK / Cookie、目录和删除开关属于高敏感配置。
  • 资源转存 / Forward：处理合法授权媒体的候选、链接和目标目录；不公开真实链接、口令、Token 或 Widget 地址。
  • Webhook：接收 Emby 事件；需要 HTTPS / 访问控制，地址不是公开 API 文档示例。
  • FNOS / Telegram：依赖 Cookie、API 信息、账号会话或验证码；只在自有账号和可信环境使用。
  • MoviePilot / TMDB / 代理：外部服务连接配置；测试成功只说明接口可达，不说明所有下游站点或资源源可用。

首次小范围验证

  1. 先打开一个低风险工具（例如外部服务连接测试），确认保存 / 测试反馈清晰。
  2. 再选一个业务工具做单条验证：一个 RSS 预览、一个 115 文件、一个 Webhook 事件或一个封面预览。
  3. 确认日志、历史和目标结果一致后，才启用长期任务；不要一次开启所有工具。

常见问题、风险与回滚

  • 卡片打不开 / 数据空：先刷新页面并看具体错误；不要把空状态当成“可以直接保存默认值”。
  • 配置保存后仍失败：回到对应工具查看测试结果和日志；不同工具的凭据和网络路径不同。
  • 误启用自动化：优先关闭启用开关并保存，再到历史 / 任务页处理已提交的工作。
  • 工具箱只是入口，不提供统一回滚；回滚方式以各子页面教程和实际任务状态为准。

按工具边界排查：工具箱

工具卡片找不到或打开为空

  1. 先清除搜索和分类筛选，确认不是被筛选条件隐藏。
  2. 打开具体工具后按该工具自己的“测试/保存”顺序操作；工具箱只负责入口，不负责统一保存。

一个工具正常但下游功能失败

  1. 连接测试只证明接口可达，不代表订阅、站点、下载、上传或整理全部正常。
  2. 回对应页面用一个小样本验证：TMDB→发现/缺集，MoviePilot→订阅/站点，115→秒传/整理，代理→真实外部请求。

保存后凭据状态消失

  1. 刷新页面确认状态，再查看系统日志中的保存接口结果。
  2. 检查 /app/config 是否持久化；容器重建后状态消失通常是配置挂载错或目录不可写。
