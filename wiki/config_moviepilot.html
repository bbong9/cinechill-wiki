工具箱 / MoviePilot

本页对应“工具箱”里的“MoviePilot”配置弹窗，只负责连接信息与连接测试。持久 API Key 用于常规接口；用户名和密码用于 MoviePilot 原生流式搜索。站点监控是首页“站点管理”中的独立功能，不要把两者混为一个开关。

适用场景与准备工作

  • 发现推荐、缺集统计或其他页面需要读取 MoviePilot 订阅 / 搜索能力时使用。
  • 准备自有 MoviePilot 的可访问地址、用户名、密码和持久 API Key。地址必须从 CineChill 运行环境可达。
  • 不把真实地址、账号和 Key 写进 Wiki；文档中的示例只能作为格式提示。

按页面顺序操作

  1. 从左侧进入“工具箱”，点击“MoviePilot”卡片，打开配置弹窗；关闭后返回工具箱。
  2. 在“连接信息”依次填写“MoviePilot 地址”“持久 API Key”“用户名”和“密码”。Key 已存在时，页面支持留空以保留已配置值。
  3. 点击“保存配置”保存，或点击“测试连接”让页面先保存当前表单再立即调用测试接口。
  4. 在右侧“可用能力”确认配置、连接、常规接口和流式搜索状态。
  5. 回到“发现推荐”只对一个条目发送 MP 订阅；需要站点监控时再打开首页“站点管理”单独配置。

字段解释

  • MoviePilot 地址：后端访问的服务地址，不等于浏览器地址栏；容器部署时应使用实际可达的服务名或地址。
  • 持久 API Key：用于常规 API 调用，例如订阅、下载和普通搜索；保存后页面只显示“已配置”状态。
  • 用户名 / 密码：用于原生流式搜索的账号登录；不要把它们当作 API Key 的替代品。
  • 测试连接：测试结果显示在“连接”状态，不代表每个站点、下载器或搜索源都健康。

首次小范围验证

  1. 先只填写必要字段并保存，确认配置状态从“待配置”变成“已配置”。
  2. 点击“测试连接”，确认弹窗右侧“可用能力”中的连接状态显示“可用”。
  3. 在发现页对一部电影或一季电视剧发送一次 MP 订阅，再到订阅管理核对。

常见问题、风险与回滚

  • 测试失败：依次检查地址可达性、账号密码、API Key 和 CineChill 容器网络；不要先改站点监控配置。
  • 常规接口可用但流式搜索失败：检查用户名和密码；两条能力的认证路径不同。
  • 换服务：保存新地址和凭据后再次测试；若要停用联动，清空配置并保存，再确认发现页不再发送订阅。
  • 连接配置不会自动撤销已经发出的订阅或下载任务；回滚需要到订阅 / 任务页面单独取消。

MoviePilot 与 CineChill 的分工

组件负责什么你要验证什么
MoviePilot订阅、搜索、站点监控、下载和按配置生成硬链接。连接可用、下载器可用、硬链接目录可写。
CineChill监控待处理目录、115 秒传、媒体识别、整理、STRM 和 Emby 联动。能看到同一个硬链接目录，整理目标路径正确。
Emby读取最终媒体库、刷新元数据并提供播放。媒体路径和 CineChill 的最终入库路径一致。

硬链接配置的关键

  1. 在 MoviePilot 中把硬链接输出目录设为 CineChill 能访问的专用待处理目录。
  2. 确保下载源和硬链接目录位于同一文件系统；跨盘通常无法创建真正的硬链接。
  3. 在 Docker Compose 中把该宿主机目录同时映射给 MoviePilot 和 CineChill，容器内路径也要保持可对应。
  4. 先下载一个小文件，确认硬链接出现且 CineChill 能读取，再开启批量监控。

不要混淆：MoviePilot 配置页的“连接测试”只证明接口认证和服务可达，不代表站点、下载器、硬链接和入库链路都正常。

按链路排查：MoviePilot 连接与硬链接

连接测试失败

  1. 检查 MoviePilot 地址是否从 CineChill 容器可达；不要把浏览器地址栏可用当成容器可用。
  2. 401/403 查持久 API Key；流式搜索失败再查用户名/密码，二者不是互相替代的凭据。
  3. 修复后确认页面显示“已配置/连接正常”，再去站点管理或订阅系统验证实际接口。

站点能发现资源但下载任务没有创建

  1. 先确认候选的标题、年份、季集和质量满足筛选条件；严格匹配会主动过滤缺少关键字段的资源。
  2. 查看站点管理和系统日志，区分“候选被过滤”“请求 MP 失败”“MP 已创建任务但下载器拒绝”。
  3. 只对一条候选重试，并在 MoviePilot 外部任务页确认是否出现任务，不要连续提交同一候选。

下载完成但硬链接目录没有文件

  1. 确认下载器任务状态为完成，并在宿主机找到原始下载文件。
  2. 检查下载目录和硬链接目录是否同一文件系统；跨盘、跨挂载通常不能创建真正硬链接。
  3. 检查 MP 容器两端路径映射和写权限，再用一个小文件重新验证。
