TMDB 配置

配置 TMDB 和豆瓣相关元数据来源，用于识别、刮削、缺集统计和发现推荐。

这页是干什么的

配置 TMDB 和豆瓣相关元数据来源，用于识别、刮削、缺集统计和发现推荐。

什么时候打开它

  • 媒体整理识别不准
  • 缺集统计无法比对
  • 发现推荐没有详情

小白第一次怎么用

  1. 填写 TMDB API Key。
  2. 必要时配置代理。
  3. 可选填写豆瓣 Cookie。
  4. 保存后回一条龙菜单或缺集统计测试。
  5. 遇到识别错误时优先检查标题、年份和 TMDB 连接。

页面区域怎么看

  • TMDB Key：元数据主凭据。
  • 豆瓣 Cookie：可选辅助来源。
  • 代理：访问 TMDB 不稳定时使用。

常见问题和排查

  • TMDB Key 错误会影响多个模块。
  • 代理不可用会造成刮削超时。
  • 片名太模糊时重命名模板也要配合调整。

使用前的通用提醒

  • 先只填必要配置，不要一开始就打开所有自动化开关。
  • 每次保存后先点测试、刷新或手动运行一次，确认链路正常再进入下一步。
  • 遇到红色错误提示时，先看当前页的状态卡片，再去“实时日志”按时间搜索。
  • 涉及 Cookie、Token、API Key 的输入框只需要填写自己的值，Wiki 不会展示真实密钥。
