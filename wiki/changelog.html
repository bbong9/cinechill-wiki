v1.0.0.8

2026-06-15

NEWRSS 真实库榜单升级

内置榜单：TMDB、Netflix、Apple TV+、Disney+、爱奇艺、腾讯视频 / WeTV 推荐源细分更多榜单，并把推荐源集中靠前显示。

读取上限：所有内置源和自定义 RSS 同步统一限制前 500 条媒体，避免热门榜单一次拉取数千页导致预览或同步超时。

卡片统计：真实库订阅卡片新增榜单数量、解析数量和硬链接数，分别对应 RSS 条目、TMDB 命中和成功硬链接数量。

FIX预览稳定性

TMDB 请求：原生 TMDB 榜单统一走共享限速、代理和重试逻辑，预览时默认缩小采样，减少 502、SSL EOF 和 20 秒超时。

封面显示：预览会修正 TMDB 相对海报地址，并为爱奇艺、B 站、腾讯视频、芒果 TV、咪咕等来源提供图片代理，减少外站防盗链导致的无图。

预览界面：新建订阅预览改为类似发现页的海报平铺，预览按钮移动到底部，卡片高度不再被长标题撑开。

REL发布与升级

正式版本：本次版本号为 v1.0.0.8。

Docker 镜像：发布 chillne/cinechill:v1.0.0.8、chillne/cinechill:1.0.0.8 和 latest。

升级建议：使用 RSS 真实库、内置榜单或 TMDB 推荐源的用户建议更新到本版本。

卡片居中：手机端登录卡片改为在可视区域内上下左右居中，两侧保留安全留白，避免贴边或偏移。

欢迎文案：保留左上欢迎文案，并下移到安全位置，避免被移动浏览器地址栏裁切。

书签图标：补齐 Web App manifest、apple touch icon 与主题色配置，改善手机保存书签时的图标识别。

REL发布与升级

正式版本：本次版本号为 v1.0.0.7。

Docker 镜像：发布 chillne/cinechill:v1.0.0.7、chillne/cinechill:1.0.0.7 和 latest。

升级建议：使用手机登录或保存书签的用户建议更新到本版本。

v1.0.0.5

2026-06-15

NEW手机端管理体验

顶部交互：修复手机端搜索弹层被遮挡、头像和更多菜单点击无反应的问题，并优化侧边栏弹出层级与过渡。

主题切换：手机端更多菜单新增日间、夜间和跟随系统入口，不再只能依赖默认设置。

仪表盘密度：移动端隐藏媒体库总览大卡片，压缩问候卡片并把日历移到文字右侧，减少首屏占用。

UI高频页面重排

发现与缺集：手机端推荐和缺集统计海报改为一行三列，提升浏览效率。

整理设置：一条龙、二级分类和重命名模板移除多余刷新按钮，统一按钮样式、卡片位置和右对齐规则。

整理记录：移动端记录卡片重新排版，海报放大，标题、状态、标签和时间对齐更紧凑。

REL发布与升级

账户与 Docker：账户管理补齐手机端 Emby 用户列表，搜索、刷新和新建用户同排；Docker 版本移动到镜像管理行并右对齐。

正式版本：本次版本号为 v1.0.0.5。

Docker 镜像：发布 chillne/cinechill:v1.0.0.5、chillne/cinechill:1.0.0.5 和 latest。

v1.0.0.4

2026-06-15

NEW后台界面统一整理

卡片与表格重排：优化 Webhook、资源转存、资源配置、封面资源、封面备份、自动封面、整理记录和账号管理等页面布局。

侧边栏与动效：修正窄屏菜单点击区域、选中态和图标居中问题，并放慢页面切换、卡片弹出和加载动效。

日志与筛选区：整理实时日志筛选工具栏和整理记录筛选区域，减少多余边框与无效说明。

FIX交互与数据刷新

Webhook 复制：修复 Webhook 地址复制按钮无效的问题。

继续观看加载：宽屏下会主动补充加载继续观看条目，避免只有窄屏横向滚动时才出现更多数据。

自动封面编辑：点击编辑时会刷新 Emby 媒体库，新增媒体库后能进入目标选择。

REL发布与升级

正式版本：本次版本号为 v1.0.0.4。

Docker 镜像：发布 chillne/cinechill:v1.0.0.4、chillne/cinechill:1.0.0.4 和 latest。

升级范围：适合需要后台界面、交互细节和数据刷新体验优化的用户升级。

v1.0.0.3

2026-06-14

NEW仪表盘继续观看

绑定用户生效：账户管理中绑定的 Emby 用户现在会用于仪表盘“继续观看”，播放进度不再固定读取默认用户。

概览缓存隔离：仪表盘缓存按绑定用户区分，切换绑定用户后不会继续显示上一位用户的继续观看数据。

统计范围保持全局：媒体库总览、最近入库和服务器信息继续使用管理员视角，避免绑定用户影响全局统计。

UI页面布局调整

二级分类更清爽：移除高级 JSON 编辑区，把“Emby 同步与规则维护”移动到规则卡片上方，规则维护路径更直接。

仪表盘卡片优化：继续观看卡片适当缩小，媒体库卡片保持图片铺满并稳定显示两排，减少横向滚动和视觉空洞。

账户页减少无效入口：移除没有实际必要的重复刷新按钮，只保留 Emby 用户列表工具栏里的刷新动作。

DOC发布与文档

正式镜像发布：同步发布 v1.0.0.3 Docker 镜像，用户可按常规升级流程更新到最新版本。

更新日志补齐：Wiki 更新日志补齐从 v1.0.0.1 到最新版本的正式发布记录，便于回看版本变化。

升级提示更清晰：把本次影响范围集中说明为仪表盘、二级分类、账户管理和媒体库卡片布局。
