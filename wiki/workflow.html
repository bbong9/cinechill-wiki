常用工作流

新版后台入口调整后，常用流程可以按“发现/配置 → 整理 → 验证 → 通知/自动化”串起来。

本页怎么用

常用工作流：实际操作指南

把每条链路拆成可验收的阶段：配置 → 发现/转存 → 下载或上传 → 整理 → Emby 刷新。上一阶段没有正常信号时，不要直接操作下一阶段。

按这个顺序操作

  1. 资源入库：服务器配置确认 Emby/115，TMDB 和模板保存，待处理目录与成品库分开。
  2. 下载完成后：先确认 MP 硬链接目录出现文件，再用 115 秒传进入整理目录；不要把下载目录直接当成成品库。
  3. 媒体整理：一条龙只跑一个样本，去整理记录核对识别、目标路径、命名和 STRM，再等 Emby 刷新。
  4. 缺集补齐：缺集统计核对季集后创建订阅/下载，下载完成重新整理，再重新统计缺集。
  5. 封面流程：资源配置 → 封面设计预览 → 封面备份 → 手动/自动应用 → Emby 核对；不满意先恢复快照。

完成后看什么

  • 每阶段都有对应正常信号：任务记录、目标文件、整理记录、Emby 可见、缺集数量变化。
  • 失败时能明确停在配置、下载、上传、整理或刷新中的某一步。

小白最容易错在哪里

  • 把通知发送成功当成入库成功；通知只是结果提示。
  • 前一步没有记录就直接重试后一步，容易造成重复任务和重复文件。

资源入库一条龙

适用于“待整理目录 → 识别/刮削 → 重命名 → 分类 → STRM/Emby 刷新”的完整链路。每一步都要能单独验证，不要把外部订阅、下载完成和 CineChill 入库混成一个结果。

  1. 先在服务器配置确认 Emby、115 和媒体根目录可用，在 TMDB 配置确认元数据连接可用。
  2. 把自有合法授权媒体放入待整理源目录；源目录与成品媒体库分开，避免重复扫描。
  3. 在重命名模板和二级分类中确认电影/剧集模板、Season 格式、匹配规则和目标路径。
  4. 在一条龙菜单先保存策略，再只选择一个电影或一季剧集执行；需要 STRM 时先验证增量同步，不要先跑全量。
  5. 到整理记录核对识别、目标路径、洗版/STRM 状态，再到 Emby 任务中心或 Emby 后台确认扫描完成。
  6. 最后回缺集统计或仪表盘复查；通知只代表 CineChill 发出了结果，不代表 Emby 一定已入库。

失败定位顺序：先看整理记录 → 再看系统运行日志 → 回对应配置页测试 → 修复后重跑同一个样本。

封面生产流程

推荐使用“先预览、再应用、可恢复、最后自动化”的顺序。生成预览成功不等于已替换 Emby 封面，应用后还要回 Emby 核对。

  1. 在资源配置确认布局和模板存在，在翻译配置确认展示标题策略。
  2. 在封面设计调整模板、背景、小海报、字体和角标；先保存为新模板，避免覆盖正在使用的模板。
  3. 进入手动封面，只选择一个媒体库生成预览，检查媒体库、布局、模板和取图方式。
  4. 批量应用前进入封面备份创建快照；确认后再应用封面。
  5. 回 Emby/仪表盘确认封面已更新；不满意时先恢复对应快照。
  6. 效果稳定后再在自动封面设置 Cron、目标媒体库和自动加入新库。

缺集补齐流程

缺集统计只负责对比“本地已入库季集”和 TMDB/Emby 预期，不会自动证明资源已经下载。补齐过程要分为“确认误差 → 发起补齐 → 下载/转存 → 整理入库 → 重新统计”五段。

  1. 按媒体库运行缺集统计，先展开目标条目核对标题、年份、TMDB ID、季号和 Emby ID。
  2. 如果只是索引旧或绑定错误，先校准索引/修正识别，不要直接删除 Emby 剧集。
  3. 确定确实缺集后，选择单集补缺或全集补缺；通过 MoviePilot/资源搜索发起任务时，只记录“已发送”状态。
  4. 下载或转存完成后，将文件放入待整理目录，用一条龙按既定模板入库。
  5. 回整理记录和 Emby 任务中心确认扫描完成，再重新跑缺集统计。
  6. 对本地确实完整但元数据不准确的条目，可标记手动完整；这不会生成缺失文件。

排障流程

  1. 先记录发生时间、当前页面、操作按钮和错误提示，避免只说“不能用”。
  2. 打开顶部“查看系统日志”，先看错误/警告，再按模块、时间范围和关键词过滤；不要先清空日志。
  3. 从顶部工具栏分别打开“健康检查”和“网络检测”弹层，区分配置缺失、路径权限、Emby 不通、外部网络不通和任务本身失败。
  4. 回对应配置页只测试一个依赖：Emby、115、TMDB、代理、MoviePilot 或通知。
  5. 修复后只重跑同一个小样本，去整理记录/任务中心/Emby 核对结果；确认后再恢复自动任务。

每一步应该看到什么

步骤正常信号不正常时先看
服务器配置Emby 已连接、115 Cookie 有效、标准目录正常服务器配置 → 系统健康
一条龙整理整理记录有源路径、目标路径和成功状态一条龙菜单 → 整理记录 → 系统日志
封面单库预览正确，Emby 实际封面更新资源配置 → 封面设计 → 封面备份
真实库/订阅RSS 有解析和匹配，订阅有正确 TMDB ID/季集真实库 → 订阅系统 → MoviePilot
站点监控候选被筛选，MoviePilot 任务出现站点管理 → MoviePilot 外部任务
硬链接/115硬链接出现，扫描/校验/上传状态推进MP 路径 → 115 秒传任务历史
最终入库整理记录成功，Emby 刷新后可播放整理记录 → 系统日志 → Emby

排障规则：只在一个步骤失败时处理该步骤；前一步没有出现正常信号，就不要跳到后一步反复点击。修复后用同一个测试样本重新走一遍。
