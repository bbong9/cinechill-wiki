控制台 / 自动封面

自动封面页把模板、取图模式、目标媒体库和 Cron 调度组合成后台任务。任务支持创建、编辑、试运行、立即运行、启停和删除；“应用封面”属于可能覆盖现有封面的操作。

本页怎么用

自动封面：实际操作指南

自动封面是定时任务，不是实时预览。必须先用手动封面验证模板，再创建单库、低频、停用状态的任务。

按这个顺序操作

  1. 确认模板、字体、素材和 Emby 连接正常，先在封面备份创建快照。
  2. 点击添加任务，填写任务名称和 Cron，选择取图模式、布局、预设和一个测试媒体库。
  3. 首次关闭“自动添加新建库”，关闭任务启用，先点击试运行查看效果。
  4. 试运行确认成功后创建任务，再用任务卡片的运行按钮手动执行一次。
  5. 确认 Emby 封面正确后再启用 Cron；调整任务时先停用，删除任务只删除调度，不会自动恢复已应用封面。

完成后看什么

  • 试运行和手动运行都有完成记录，目标库封面正确。
  • 启用后页面显示下次运行时间，任务历史能看到每次结果。

小白最容易错在哪里

  • 一创建就启用全库任务，导致一次覆盖范围过大；先单库试运行。
  • 停用任务就以为封面自动恢复；恢复要到封面备份执行。

适用场景与准备工作

  • 模板已经在手动封面中验证，需要按计划更新一个或多个媒体库。
  • 准备稳定的模板、可用字体 / 素材、Emby 连接和一个测试媒体库。
  • 批量前必须先做封面备份；新任务先停用或只选一个媒体库。

按 UI 顺序操作

  1. 进入“封面系统 → 自动封面”；如果当前没有任务，点击页面上的“添加任务”卡片创建任务。
  2. 填写任务名称和“执行频率 (Cron)”，选择是否启用。
  3. 按需打开“自动添加新建库”；首次建议关闭，避免新媒体库自动加入批量范围。
  4. 选择取图模式、布局模式和预设；在“目标媒体库”只勾选一个测试库。
  5. 任务创建后按页面提供的试运行/运行入口先做单库验证；执行前确认可能覆盖目标封面。
  6. 在弹窗中点击“试运行”做一次小范围验证；确认结果后点击“创建任务”，再用任务卡片“运行”或启用 Cron。

字段与生命周期

  • 执行频率 (Cron)：后台调度表达式；不要设置得比媒体库变化更频繁。
  • 自动添加新建库：任务运行时包含当前新增 Emby 媒体库；打开后目标范围会动态扩大。
  • 取图模式 / 布局模式 / 选择预设：决定素材和渲染方式，预设必须属于当前布局。
  • 目标媒体库：固定勾选的库；页面展示已选择数量。
  • 运行 / 启停 / 编辑 / 删除：运行启动后台任务；停用只阻止后续调度；删除不会自动恢复已生成封面。

首次小范围验证

  1. 先做封面备份，创建一个停用的测试任务，只选择一个库。
  2. 点击试运行或立即运行，确认日志无渲染、权限和 Emby 错误。
  3. 回 Emby 检查封面，再决定是否启用任务、增加目标库或打开自动添加新库。

常见问题、风险与回滚

  • 没有媒体库：检查 Emby 地址 / API Key 与连接；页面会提示“未读取到媒体库”。
  • 任务运行失败：检查预设、字体、素材和日志；不要连续点击运行创建并发任务。
  • 批量效果不满意：先停用任务，再从封面备份恢复目标库，最后修改模板或任务。
  • 删除任务：只删除自动任务配置，不等于恢复已生成封面。

自动封面启用前的检查清单

  1. 模板已经在封面设计中另存并预览成功。
  2. 封面资源、字体和 Emby 连接均可用。
  3. 封面备份中有最近一次可恢复快照。
  4. 自动任务先保持停用，只选择一个测试媒体库。
  5. 试运行或立即运行成功后，再设置 Cron 和自动添加新建库。

运行、停用和删除的区别

  • 运行：立即启动一次后台处理，可能覆盖目标媒体库封面。
  • 停用：只阻止后续调度，不会恢复已经生成的封面。
  • 编辑：修改模板、取图、目标库或频率；修改后要重新做单库验证。
  • 删除：删除任务配置，不等于撤销已应用的封面。

出现异常时：先停用任务，再从封面备份恢复目标库，最后修改模板或任务；不要连续点击“运行”制造并发任务。

按现象排查：自动封面

任务创建了但没有按 Cron 运行

  1. 打开任务卡片确认“启用”状态，检查执行频率是否是有效的五段 Cron，而不是只填写了任务名称。
  2. 确认目标媒体库至少勾选一个；“自动添加新建库”不会替代固定目标库的首次验证。
  3. 记录当前时间和时区，等待下一次计划时间；不要用连续点击“运行”代替 Cron 验证。
  4. 到系统运行日志按任务名称过滤，区分“未触发”“触发后失败”和“触发后没有媒体”。

立即运行/试运行失败

  1. 先确认手动封面能用同一模板和同一媒体库生成预览；手动都失败时不要查 Cron。
  2. 检查模板、字体、素材和 Emby 连接，日志中出现哪个资源不存在就先修哪个资源。
  3. 只选择一个媒体库重新试运行；成功后再增加库，不要直接运行全库。

重复生成、覆盖范围过大或效果不满意

  1. 立即停用任务，记录任务名称、运行时间和目标媒体库；停用只阻止后续调度，不会撤销已生成封面。
  2. 检查是否存在重复任务、多个任务选择同一媒体库，或打开了“自动添加新建库”。
  3. 恢复前先确认封面备份套件和目标库，恢复一个库验证后再处理其他库。
  4. 修正模板后使用“另存为”建立新版本，再让任务选择新模板。
