缺集统计

新版缺集统计用于按媒体库扫描剧集完整性，筛选缺集、异常入库、完整入库和已标记完整状态。

本页怎么用

缺集统计：实际操作指南

缺集统计必须等索引完成后再判断。展开剧集对照本地季集和 TMDB 季集，再选择补缺、校准或手动标记。

按这个顺序操作

  1. 选择一个电视剧媒体库和“单季模式”或“全季模式”，点击“开始统计”；索引构建/统计进行中时不要重复点击。
  2. 统计完成后再用媒体库、缺集类型、日期、缺集数量/比例和标题排序筛选，点击剧集卡片展开详情。
  3. 对照本地已入库季集、TMDB 季集、缺失集号、TMDB ID 和 Emby ID；识别错误先点“校准索引”。
  4. 确认真缺集后点“搜索资源”或“MoviePilot 订阅”，选择单集补缺/全剧补缺；下载整理完成后重新统计。
  5. “标记为完整”只改变统计状态，不会生成文件；“删除剧集”会调用 Emby 删除，必须先确认 Emby ID。

完成后看什么

  • 统计进度完成，详情能显示具体缺失集号。
  • 补缺/整理后重新统计，缺集数量按预期减少；手动完整条目进入对应筛选。

小白最容易错在哪里

  • 索引还没完成就判断页面没有数据。
  • Emby 尚未刷新就重新统计，导致旧结果继续显示。
  • 把手动完整当成补文件，或未核对 Emby ID 就删除剧集。

新版入口

左侧导航栏点击“缺集统计”。页面顶部提供媒体库选择、全季/单季模式、开始统计、校准索引和 MoviePilot 补缺入口；列表中的条目展开后还能查看季集、搜索资源、标记完整或删除 Emby 剧集。

这页是干什么的

对照本地 Emby 剧集与元数据，找出缺季、缺集、异常入库或已完整的条目。

什么时候打开它

  • 想检查某个剧集库是否完整。
  • 整理完成后需要复查是否还有缺集。
  • 需要按缺集数量或比例确定优先处理对象。

小白第一次怎么用

  1. 选择要统计的电视剧媒体库；首次建议只选一个库，并先选择“单季模式”或“全季模式”。
  2. 点击“开始统计”，等待进度完成；数据为空时先确认 Emby 连接和库缓存。
  3. 用全局搜索、媒体库、缺集类型和排序条件定位目标，展开条目查看本地已入库季集与 TMDB 季集。
  4. 若只是误判，先核对标题、年份、季号、TMDB ID 和 Emby ID；需要重新读取库时点击“校准索引”。
  5. 补缺前切换 MoviePilot 的“单集补缺/全集补缺”模式，或使用资源搜索/转存流程；完成后重新统计，确认缺集数量变化。
  6. 只有确认条目错误且接受不可逆影响时，才使用“删除剧集”；对本地已完整但不应继续统计的条目可使用“标记手动完整”。

页面区域怎么看

  • 模式选择：单季模式适合局部核对，全季模式适合整部剧复查；MoviePilot 补缺模式另有“单集补缺/全集补缺”。
  • 统计对象：当前扫描的剧集数量、已入库集数和预计集数。
  • 媒体库与缺集筛选：可区分连载未缺集、连载已播缺集、已完结缺集、单季完整入库等状态。
  • 排序与搜索：按缺集数量、标题、年份或 TMDB 关键字定位。
  • 条目详情：展示本地季集、TMDB 季集、缺失集号、Emby/TMDB 跳转和手动完整标记。
  • 操作区：搜索资源、MoviePilot 订阅、标记手动完整、删除 Emby 剧集；删除前必须确认目标。

验证方式

  1. 进度完成，统计摘要和媒体库数量与 Emby 大致一致。
  2. 展开一个条目，确认“本地已入库季集”和“TMDB 季集”都能读取；异常条目能指出缺失或多出的集号。
  3. 补齐、校准或手动标记后重新统计，目标条目的状态/缺集数量发生预期变化。
  4. 如果执行了 MoviePilot 订阅，只能说明“已发送订阅”，不能把订阅成功当成媒体已经下载或入库。

常见问题和风险

  • 缺集统计依赖 Emby、TMDB 和正确的标题/季集识别；TMDB 不通、绑定错条目或本地缓存未刷新都会造成误判。
  • “手动完整”只是让统计暂不计入缺集，不会补齐文件；取消标记后会重新参与统计。
  • “删除 Emby 剧集”会直接调用 Emby 删除接口，CineChill 内不能撤销；是否同时删除媒体文件取决于 Emby 权限和媒体库设置，执行前先备份并确认。
  • MoviePilot/资源搜索显示有结果不等于下载、转存或入库已经成功，最终要回整理记录和 Emby 核对。

按差异结果排查：缺集统计

统计显示整季缺失，但本地明明有文件

  1. 展开条目核对标题、年份、TMDB ID、Emby ID、季号和集号，不要只看缺失数量。
  2. 确认 Emby 已完成媒体库刷新；旧索引会把已存在的文件算成缺失。
  3. 识别错误时先修映射或重新刷新，再重新统计，不要直接删除剧集。

点击补缺后没有下载或订阅

  1. 记录补缺方式和时间，去 MoviePilot 配置测试连接，再看订阅系统是否出现记录。
  2. “已发送”只表示请求发出，不代表下载完成；继续看站点监控、下载任务、硬链接和整理记录。
  3. 下载/整理完成后重新刷新 Emby 并重新运行缺集统计。

误把完整剧集标记为手动完整

  1. 先确认本地文件和 Emby 季集真实完整；手动完整只改变统计状态，不会生成缺失文件。
  2. 发现实际缺集时取消错误标记，再按单集流程补齐并重新统计。
