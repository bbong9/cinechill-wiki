入门

部署与首次配置

CineChill 通常跑在 NAS 或 Docker 主机上。部署完成后，真正决定体验的是配置顺序。

推荐配置顺序

  1. 部署容器或本地服务，确认管理端能打开。
  2. 账户管理：改掉默认账号。
  3. Emby 配置：填地址和 API Key，测试连接。
  4. 115 配置：填 Cookie，确认能读目录。
  5. 代理配置：如果 TMDB 或 Telegram 访问不稳定，先配置代理。
  6. TMDB 配置：填 Key，作为识别、缺集和推荐的基础。
  7. 通知配置：至少配置一种通知渠道。
  8. 最后再配置一条龙、真实库、自动封面等自动化。

哪些目录要备份

  • config：最重要，包含账号、配置、任务状态和缓存。
  • fonts/templates/layouts：决定封面生成效果。
  • backups：封面备份套件。
  • 升级或迁移前先备份这些目录。
