工具箱 / Forward 模块

Forward 模块负责 Widget 访问、资源库补充匹配、爱影搜索、转存模式、Token 和单个 TMDB ID 测试。它是资源候选与联动配置，不是公开资源目录；仅面向自用合法场景。

适用场景与准备工作

  • 为自用发现页 / Widget 提供资源候选，或在合法授权媒体流程中测试单个条目匹配。
  • 准备自有访问地址；如果启用爱影，还要准备对应的 Telegram ID 和 Chill Token。
  • 先确认 115 和通知 / Telegram 等依赖已配置；不要把 Widget 地址当成可公开分享链接。

按 UI 顺序操作

  1. 从“工具箱”点击“Forward 模块”卡片，打开当前弹窗，等待配置和搜索源加载。
  2. 在“Forward 配置”选择“启用 Forward”“启用资源库”，填写公开访问地址；需要转存时选择“整剧模式”或“单集模式”。
  3. 在“爱影配置”按需打开爱影搜索，填写 Telegram ID 和 Chill Token；不使用时保持关闭。
  4. 点击“保存 Forward”或“保存爱影”，确认卡片状态和搜索源数量。
  5. 需要自用 Widget 时，在“Widget Token”生成 / 刷新地址并复制到可信前端；刷新 Token 前先确认旧地址会失效。
  6. 在“资源测试”填写一个合法 TMDB ID 和媒体类型，点击测试，先看单条返回再进入发现页。

字段解释

  • 启用 Forward：控制 Widget 和 Forward 接口是否可访问。
  • 启用资源库：允许使用 CineChill 本地资源库做补充匹配。
  • 公开访问地址：用于拼接 Widget 地址；应使用受控域名 / 反向代理，不要裸露内部服务。
  • 转存模式：整剧或单集会影响后续转存选择，不代表自动执行资源转存。
  • 爱影开关 / Telegram ID / Chill Token：仅控制爱影搜索调用；Token、ID 和结果不要公开。
  • 调用统计：展示今日使用、成功次数和最近调用，是运维指标，不是资源清单。

首次小范围验证

  1. 先只启用 Forward，不启用爱影，保存后确认状态。
  2. 只测试一个 TMDB ID，确认有结果 / 无结果 / 失败提示都能正常显示。
  3. 再复制 Widget 地址到自己的受控前端，确认读取成功；不要放到公开演示站。

常见问题、风险与回滚

  • 没有搜索源：检查 Forward 配置和后端返回的搜索源，不要手动编造源名称。
  • Widget 失效：确认是否刷新过 Token；刷新后必须替换自用前端的旧地址。
  • 调用失败：先关闭不需要的爱影联动，检查 ID / Token 和系统日志。
  • 停用：关闭 Forward 并保存可阻止新访问；已发起的后台转存或下载不一定自动取消，要到对应任务页处理。

按阶段排查：Forward 模块

Widget、Token 或资源库连接失败

  1. 先测试 Widget 地址和 Token，检查地址是否从 CineChill 容器可达。
  2. 401/403 查 Token 权限，超时查代理/DNS/容器网络；不要直接换一套配置覆盖原值。
  3. 连接成功后只用一个 TMDB ID 测试，确认返回候选再进入转存。

搜索有结果但转存失败

  1. 检查目标 115 Cookie、目标目录和转存模式；搜索成功不代表转存账号可用。
  2. 查看任务历史区分候选解析、转存提交和远端移动失败。
  3. 先保留源任务和目标文件，确认少量文件到位后再开启批量。
