仪表盘

作为每天打开 CineChill 的总入口，集中查看媒体库状态、任务动态、服务器资源、最近入库和继续观看。

这页是干什么的

作为每天打开 CineChill 的总入口，集中查看媒体库状态、任务动态、服务器资源、最近入库和继续观看。

什么时候打开它

  • 刚登录后想确认系统是否正常
  • 想快速跳转到媒体整理、封面、真实库、缺集统计等常用页面
  • 排查“今天有没有任务失败、Emby 是否连上、媒体库有没有数据”

小白第一次怎么用

  1. 查看顶部问候和日期，确认当前登录用户正确。
  2. 检查“媒体库总览”，电影、电视剧、剧集和用户数量应与 Emby 大致一致。
  3. 查看“任务动态”，如果某类任务不在待机状态，先不要重复点击运行。
  4. 看“服务器状态”，CPU、内存、硬盘和网络异常时先进入系统健康。
  5. 从继续观看、最近入库或媒体库区域判断 Emby 数据是否已成功刷新。

页面区域怎么看

  • 媒体库总览：来自 Emby 的库、电影、电视剧、剧集和用户摘要。
  • 任务动态：媒体整理、STRM、Webhook、RSS 等后台任务状态。
  • 入库趋势：最近 7 天、30 天或全部新增内容趋势。
  • 继续观看：来自 Emby 的播放进度。

常见问题和排查

  • 如果页面提示 500，通常是后端接口或本地配置未就绪，先看实时日志。
  • 如果媒体库全部为 0，优先检查 Emby 配置页的地址和 API Key。
  • 如果任务长期 running，进入实时日志或整理记录查 run id。

使用前的通用提醒

  • 先只填必要配置，不要一开始就打开所有自动化开关。
  • 每次保存后先点测试、刷新或手动运行一次，确认链路正常再进入下一步。
  • 遇到红色错误提示时，先看当前页的状态卡片，再去“实时日志”按时间搜索。
  • 涉及 Cookie、Token、API Key 的输入框只需要填写自己的值，Wiki 不会展示真实密钥。
