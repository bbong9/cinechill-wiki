账户管理

账户管理包含两部分：CineChill 管理员登录凭据，以及基于主 Emby 服务器的用户查看、绑定和维护。先处理管理员凭据，再操作 Emby 用户。

本页怎么用

账户管理：实际操作指南

先修改 CineChill 管理员凭据，再维护 Emby 用户。两套账号分开保存，不能把 Emby 用户操作当成管理员设置。

按这个顺序操作

  1. 在当前账户卡片确认用户名、账户类型和密码保存状态；进入“修改登录凭据”填写旧密码、新用户名和新密码，点击“保存账户”。
  2. 退出并用新凭据重新登录，确认旧密码无法继续使用，再刷新账户管理。
  3. 确认服务器配置的 Emby 已测试通过后，到账户管理的 Emby 用户卡片搜索用户名/UserId，点击刷新读取列表。
  4. 对一个用户打开行内操作菜单，执行编辑、禁用/启用、重置密码、头像或绑定操作；每次操作后刷新表格确认状态列变化。
  5. 删除用户前确认删除对象和二次确认内容；操作后回 Emby 用户列表核对，不能只看 CineChill 弹窗。

完成后看什么

  • 管理员凭据可以重新登录，Emby 用户列表能读取。
  • 单个用户操作后状态、最后活动或绑定列变化与 Emby 侧一致。

小白最容易错在哪里

  • 管理员密码和 Emby 用户密码混为一谈。
  • Emby 用户列表为空时反复操作；先查服务器配置、API Key 和 Emby 网络。
  • 未确认删除对象就点击删除；先打开详情/菜单并完成二次确认。

适用场景与前置条件

  • 首次登录后修改管理员账户、怀疑凭据泄露、或需要维护 Emby 用户时使用。
  • 全新部署的初始账号是 admin，初始密码是 password；只应作为首次登录凭据，不能长期保留。
  • 修改 CineChill 管理员只需要当前旧密码；维护 Emby 用户前，必须先在服务器配置完成主 Emby 地址和 API Key。
  • Emby 用户的真实数据存储在 Emby 服务端；CineChill 只保存绑定关系和调用 Emby API。

修改 CineChill 登录凭据

  1. 在“修改登录凭据”填写当前旧密码；首次修改时填写初始密码 password。
  2. 填写“新用户名”和“新密码”。三项缺一不可。
  3. 点击“保存账户”。后端会写入认证配置；新密码不会在前端持久化。
  4. 退出或刷新后，用新凭据重新登录。

如果修改了用户名，旧会话会因当前用户名变化而失效；如果只改密码，已有签名会话不会自动全部撤销，因此怀疑泄露时还应轮换用户名/会话并检查访问入口。

Emby 用户：常用操作

  • 刷新/搜索：重新读取主 Emby 用户列表，可按名称、ID、角色或状态筛选。
  • 绑定：从列表绑定，或粘贴 Emby UserId/用户页 URL；绑定关系供其他功能识别当前用户。
  • 新建：填写用户名称，可选择模板用户并设置初始密码。
  • 编辑：修改名称、管理员/禁用/隐藏策略、媒体播放和下载权限，以及自动播放/音频/字幕记忆等配置。
  • 禁用/启用：直接改变 Emby 用户能否登录。
  • 重置密码：在用户编辑中提交新密码。
  • 头像：可生成、上传或同步到 Emby；后端限制头像文件不超过 2MB，支持常见 JPG/PNG/WebP/SVG 图片。
  • 删除：会真实删除 Emby 用户；已绑定用户不能删除，删除前必须确认影响范围。

首次验证

  1. 重新登录 CineChill，确认顶部用户名已更新。
  2. 刷新 Emby 用户列表，确认用户名称、角色、状态和绑定标记符合预期。
  3. 若修改了禁用、管理员或播放策略，用对应 Emby 用户实际登录/播放一次验证。
  4. 若上传头像，回 Emby 用户界面确认头像已同步，而不是只看 CineChill 预览。

失败排查

  • 保存管理员失败：确认旧密码正确；不要通过修改公开文档解决认证问题。
  • Emby 用户列表为空或读取失败：先检查服务器配置的 Emby 测试结果和 API Key 权限。
  • 绑定失败：确认 UserId 属于当前主 Emby，粘贴 URL 时保留完整的用户 ID 参数。
  • 不能删除用户：先检查是否为 CineChill 当前绑定用户；这是后端的保护条件。
  • 头像上传失败：检查图片类型、文件大小和 Emby API 连接。

备份与回滚

  • 管理员凭据和 CineChill 的 Emby 绑定关系属于配置备份范围；Emby 用户本身要通过 Emby 的备份机制保护。
  • 批量修改 Emby 用户前先记录原策略或做 Emby 端备份；回滚时逐项恢复，不要直接删除重建用户。
  • 凭据、UserId、头像和活动信息不要公开截图或写入日志附件。

按操作排查：账户管理

默认账号不能登录

  1. 只对“全新配置且没有认证文件”的实例使用 admin / password；已有 config 时以当前配置为准。
  2. 确认访问的是当前容器的 5256 端口，不是旧容器或旧反向代理。
  3. 登录成功后立即修改凭据，并退出后用新凭据重新登录验证。

Emby 用户列表为空或操作失败

  1. 回服务器配置测试主 Emby，确认 API Key 能读取用户和系统信息。
  2. 刷新列表后再按名称搜索；绑定时核对 UserId 属于当前主 Emby。
  3. 新建、禁用、重置密码或删除后，用对应 Emby 用户实际登录验证；删除操作不要用来“修复”绑定错误。

修改凭据后仍能用旧会话

  1. 先退出旧会话并关闭旧标签页，再用新凭据登录。
  2. 如果怀疑凭据泄露，同时更换用户名和密码，并检查反向代理是否仍指向旧实例。
