控制台 / 封面设计

封面设计是封面模板工作台：组合布局、预设、字体、素材和参数，保存成可复用模板。它与手动封面共用模板资源，与自动封面共用任务选择。

本页怎么用

封面设计：实际操作指南

封面设计是模板制作工作台。字段要按“目标库/布局 → 素材 → 角标与字体 → 预览 → 保存模板”的顺序调整，不能直接跳到自动任务。

按这个顺序操作

  1. 选择封面目标媒体库、布局模式、预设参数和取图模式，先确认基础画布能生成。
  2. 在素材组合中选择随机池、搜索或上传背景/小海报；素材加载失败先回资源配置检查。
  3. 调整统计角标的样式、字体、大小、颜色、透明度和当前布局提供的高级参数。
  4. 填写模板名称；覆盖旧模板用“保存当前”，保留旧版用另存为新模板。
  5. 生成预览并保存后，回资源配置刷新确认模板存在，再到手动封面单库应用。

完成后看什么

  • 预览中的标题、海报、角标和字体都正确，保存后资源配置能看到模板。
  • 手动封面能读取该模板，自动封面任务下拉也能选到。

小白最容易错在哪里

  • 模板保存成功但自动任务找不到：先回资源配置刷新并检查布局模式是否一致。
  • 一次改太多参数无法定位问题；先只改素材，再改文字和角标。

适用场景与准备工作

  • 统一多个媒体库的视觉风格，或为手动 / 自动封面准备可复用模板。
  • 先确认资源配置页能读到布局、模板和字体；准备一个测试媒体库。
  • 改已有模板前先备份，避免覆盖影响正在使用的自动任务。

按 UI 顺序操作

  1. 进入“封面系统 → 封面设计”，在封面目标区域选择媒体库、布局模式、预设参数和取图模式。
  2. 在素材组合中用随机池 / 搜索选择背景和小海报，或上传已授权素材。
  3. 调整统计角标、字体、大小、颜色、透明度和当前布局的高级参数；页面会按 schema 显示可用字段。
  4. 填写模板名称。确定覆盖已有模板时点击“保存当前”；希望保留旧版时使用另存为新模板。
  5. 点击“生成预览”检查单库效果，再到手动封面执行应用或到自动封面选择该模板。

字段解释

  • 布局模式：当前可用渲染引擎；不要根据旧截图假设固定模式名称。
  • 预设参数：从模板资源加载的默认配置；切换布局时会匹配该布局的首个模板或清空选择。
  • 背景 / 小海报：用于当前设计预览；可从随机池、搜索或本地上传加入。
  • 模板名称：保存后会出现在资源配置和自动任务的预设列表中。
  • 覆盖：源码明确提示会立即影响后续封面生成和自动任务；不确定时不要覆盖。

首次小范围验证

  1. 先另存为一个新模板，不覆盖默认模板。
  2. 只选一个测试媒体库，生成预览并检查标题、副标题、角标和素材位置。
  3. 在手动封面确认能读取新模板后，再把它用于一个自动任务。

常见问题、风险与回滚

  • 模板不显示：刷新资源配置，确认模板文件仍存在且预览可读。
  • 保存失败：检查模板名称、配置 JSON 和当前布局参数；不要直接粘贴未验证的 JSON。
  • 覆盖后效果异常：恢复封面备份，并在资源配置中删除 / 重新保存错误模板；自动任务需要重新选择稳定模板。
  • 图片与字体必须具备使用授权，公开仓库只放允许公开的素材。

封面系统的正确配置顺序

  1. 进入“资源配置”，确认布局、模板、字体和资源分类能正常加载。
  2. 进入“封面设计”，先另存为新模板，不要直接覆盖默认模板。
  3. 选一个测试媒体库生成预览，检查标题、副标题、角标、素材位置和可读性。
  4. 到“封面备份”创建快照，再在手动流程中应用一次。
  5. 确认效果后，才到“自动封面”创建 Cron 任务并扩大目标媒体库。

每个区域的作用

  • 布局模式：决定画布和渲染结构；切换布局可能让预设参数失效。
  • 预设：提供可复用的初始参数；不确定时先用当前布局的默认预设。
  • 素材组合：决定背景、小海报和取图方式；先使用已有资源验证，不要第一次就上传大量素材。
  • 统计角标：控制数量或统计展示，不负责修复媒体库统计。
  • 保存当前 / 另存为：保存当前会影响后续任务，另存为适合试验新版本。

小白注意：预览好看不代表批量应用安全。先备份、单库验证、回 Emby 检查，确认后再启用自动封面。

按现象排查：封面设计

布局、预设或模板列表为空

  1. 先去“资源配置”刷新，确认模板数量大于 0；资源为空时不要在本页反复点击生成预览。
  2. 确认当前布局与预设属于同一组；切换布局后重新选择该布局的预设，不要沿用旧布局参数。
  3. 如果只有一个浏览器页面异常，强制刷新后再次进入；如果所有页面都为空，查看系统日志和模板挂载目录。

预览空白、字体缺失或素材不显示

  1. 先只保留默认字体、默认背景和一个媒体库生成预览，判断是模板问题还是素材问题。
  2. 默认素材正常后，再一次加入自定义字体、背景和小海报；每加一项就生成一次预览。
  3. 日志出现文件不存在或权限错误时，检查 /app/fonts、/app/templates 挂载和文件名大小写。
  4. 预览成功后使用“另存为”，不要直接覆盖正在被自动任务使用的模板。

保存成功但自动封面找不到模板

  1. 记录保存时的模板名称和布局，回“资源配置”刷新确认模板实际出现。
  2. 自动任务里重新选择同一布局下的模板；不要只修改模板名称就认为任务已更新。
  3. 用一个测试媒体库试运行，确认模板、字体、素材和目标库全部匹配后再启用 Cron。
