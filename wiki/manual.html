控制台 / 手动封面

手动封面工作台用于选择媒体库、布局模式、预设、取图方式和素材，先生成预览，再决定应用。它最适合单库、单次或少量目标验证。

本页怎么用

手动封面：实际操作指南

当前版本的模板配置已并入封面设计；本页重点是单库预览和应用验收。先预览，后备份，最后应用。

按这个顺序操作

  1. 先到资源配置确认布局、模板和字体存在；到封面设计调整模板并保存。
  2. 进入手动封面区域，选择一个媒体库、布局模式、预设和取图方式。
  3. 点击生成预览，核对媒体库、模板、取图、标题和角标；预览不满意就回设计页修改。
  4. 确认后先到封面备份创建快照，再点击应用封面并在确认框检查目标媒体库。
  5. 回 Emby 打开一两个媒体核对封面，确认后才扩大到其他库。

完成后看什么

  • 预览与应用后的 Emby 封面一致，目标库没有误覆盖。
  • 封面备份能浏览并恢复目标库。

小白最容易错在哪里

  • 预览成功就认为 Emby 已更新；应用后还要回 Emby 验证。
  • 没有备份就批量应用；不满意时只能人工恢复，先创建快照。

当前版本说明

当前管理端未再提供独立的“手动封面”顶层入口。原手动封面流程已并入封面设计、资源配置和自动封面相关能力；请优先查看下面的新版页面。

  • 封面设计：编辑和保存可复用模板。
  • 资源配置：查看模板资源和布局分类。
  • 自动封面：配置预览、调度和批量应用。

适用场景与准备工作

  • 在新模板或自动任务启用前，先对一个媒体库生成预览。
  • 准备 Emby 连接、至少一个布局 / 模板和可用字体；封面资源配置页用于检查模板。
  • 准备封面备份；“应用封面”会替换当前 Emby 媒体库封面。

按 UI 顺序操作

  1. 当前版本请按用途进入“封面系统 → 封面设计”配置模板，进入“资源配置”检查资源，进入“自动封面”配置批量任务；如果你的管理端仍显示手动工作台，再按本页字段操作。
  2. 填写模板名称；需要复用时可“保存当前”覆盖已有模板，或另存为新模板。
  3. 在“素材组合”选择随机池、搜索或上传背景图 / 小海报；不需要时保持默认取图模式。
  4. 按需调整“统计角标”里的样式、字体、大小、颜色、背景 / 边框透明度；高级参数按当前布局 schema 展示。
  5. 点击“生成预览”，先检查画布和摘要中的媒体库、布局、模板、取图。
  6. 确认无误后点击“应用封面”，在确认框检查目标媒体库；不满意时不要应用，返回参数继续预览。

字段解释

  • 媒体库：当前应用目标；未选媒体库时不能预览或应用。
  • 布局模式 / 预设参数：决定渲染引擎和模板配置；改布局可能会重置或替换对应参数。
  • 取图模式：决定背景和海报素材来源；实际选项由后端 / 页面定义提供。
  • 统计角标：控制媒体库数量角标，不等同于媒体文件统计修复。
  • 高级参数：根据当前布局 schema 渲染，不要在 Wiki 中编造固定 JSON 字段。

首次小范围验证

  1. 先在封面备份页创建一个快照。
  2. 只选一个媒体库，使用现有预设生成预览，不上传自定义素材。
  3. 确认预览与目标一致后应用，回 Emby / 仪表盘检查封面；再考虑修改模板或扩大目标。

常见问题、风险与回滚

  • 预览失败：检查媒体库、Emby 连接、模板 JSON 和素材；“配置不是有效 JSON”时回到当前模板重新加载。
  • 应用后不满意：到封面备份选择对应快照，先恢复单个媒体库，再回 Emby 核对。
  • 覆盖模板：覆盖会影响后续生成和自动任务；不确定时使用另存为新模板。
  • 上传素材：只使用自有或已授权图片 / 字体，并保留本地备份。
