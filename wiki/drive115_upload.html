控制台 / 115秒传

115 秒传页把本地监听、扫描、SHA1 校验、秒传、真实上传、重试、历史和云端账号间秒传放在一个工作台。每个文件先进入校验 / 秒传判断，未命中时才可能进入真实上传，除非任务打开“秒传未命中不上传”。

截图来自 2026-08-14 本地 CineChill 管理端；真实目录、Cookie、CK、SHA1 和文件名不在公开截图中展示。 截图会跟随 Wiki 外观开关：浅色模式显示日间截图，深色模式显示夜间截图；截图仅用于说明布局，敏感字段不作为公开文档内容。

适用场景与准备工作

  • 本地上传：监听 NAS 下载目录，将自有合法授权文件上传到个人 115 目录。
  • 网盘资源秒传：云端账号间秒传位于“工具箱 → 网盘资源秒传”弹窗；它与本页的完整上传工作台不是同一个入口。
  • 准备有效的 115 连接、可读的本地目录、可写的 115 目标目录；高风险删除选项先保持关闭。

本地上传：按 UI 顺序操作

  1. 从控制台左侧直接进入“115秒传”，在“上传任务”点击“新建”。
  2. 填写“任务名称”，选择“实时监听”或“手动扫描”；第一次建议选择手动扫描。
  3. 选择本地监听目录和 115 目标目录；不要把目标直接指向成品媒体库根目录，先使用测试目录。
  4. 先关闭“启用任务”“启动时包含已有文件”“成功后删除监控文件”“整个种子全部上传后清理下载器”和“网盘无资源时禁止上传”中的高风险项，保存任务。
  5. 回到任务卡片点击“扫描”，观察“未完成上传任务”中的校验 → 秒传 → 真实上传泳道。
  6. 确认少量文件成功后，再打开任务、设置线程或改为实时监听。

字段、线程与状态

  • 监听模式：实时监听会持续接收新增文件；手动扫描只在点击“扫描”时处理。
  • 启动时包含已有文件：开启后任务首次启动会扫描目录中已有文件，目录大时不要直接启用。
  • 校验线程 / 秒传线程 / 真实上传线程：分别控制 SHA1、秒传检查和实际上传并发；应按 NAS CPU、磁盘和网络逐步提高。
  • 当前任务：展示本轮文件、进度、失败和可重试状态；单文件可取消或重试，取消不会删除本地文件。
  • 历史数据：按成功秒传、真实上传、失败文件和体积统计；清除记录只影响显示，不会删除本地或 115 文件。
  • 成功后删除监控文件：只处理当前任务监听到的路径；如果监听目录就是下载器源目录，不要开启。
  • 整个种子全部上传后清理下载器：只有同一种子所有目标文件均完成且通过复核时才清理；状态不确定会保留。

云端网盘秒传：按 UI 顺序操作

  1. 在工具箱打开“网盘资源秒传”，分别填写来源账号 CK、目标账号 CK 和较低的并发数。
  2. 点击“浏览来源”，只选择少量自有文件或文件夹；点击“浏览目标”选择目标目录，不能选择目标根目录。
  3. 确认“来源资源”列表和目标路径后点击“开始秒传”，在确认框再次检查数量、目标路径和并发。
  4. 观察总数、已处理、成功、跳过、失败和任务进度；需要停止时点击“取消”，已完成文件不会回滚。

首次小范围验证

  1. 本地模式只选一个小文件；云端模式只选一个文件夹内的少量文件。
  2. 先验证 115 目标目录出现预期结果，再扩大范围。
  3. 确认历史记录能检索文件名 / 路径 / SHA1，并且失败记录可重试。

常见问题、风险与回滚

  • 秒传未命中：这是正常分支；若任务允许真实上传，会进入上传阶段，否则记为失败。
  • 任务卡住：先看当前泳道、日志和目标目录，不要立即重复创建同一个任务；必要时停止任务再重试失败文件。
  • 误开删除：立即停用任务；已完成的远端操作不会自动回滚，本地文件和下载器任务需按实际记录单独恢复。
  • 清除历史：只清除展示记录；删除任务配置也不会自动删除已经上传的文件。
  • Cookie / CK、真实路径和文件名都属于敏感运行信息，公开文档只能使用占位示例。

监控硬链接目录 → 秒传到 115 整理目录

这是“下载完成后交给 CineChill”的关键衔接。建议把 MoviePilot 硬链接输出目录作为本地监听目录，把服务器配置创建的 115 整理 / 秒传目录作为远程目标。

  1. 进入“115秒传”，点击“上传任务 → 新建”。
  2. 任务模式先选“手动扫描”，本地监听目录选择 MP 硬链接目录，远程目标选择具体的 115 整理目录。
  3. 第一次关闭“成功后删除监控文件”“整个种子全部上传后清理下载器”等删除类选项。
  4. 保存任务，点击“扫描”，观察校验、秒传、真实上传和失败重试状态。
  5. 确认少量文件已经出现在 115 目标目录，再切换实时监听或提高并发。

秒传未命中时怎么办

  • 秒传未命中不一定是故障；任务允许真实上传时会继续上传。
  • 如果打开“秒传未命中不上传”，未命中的文件会停在失败 / 待处理状态，需要按任务设置处理。
  • 不要把监听目录设置成成品媒体库根目录，也不要在未验证前打开自动删除。

通过标准：一个小文件能从 MP 硬链接目录被 CineChill 读取，115 目标目录能看到结果，任务历史能定位文件名和 SHA1，且本地源文件没有被误删。
