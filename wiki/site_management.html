站点管理

站点管理用于查看 MoviePilot 站点监控、资源统计和自动处理状态。它是“监控与筛选”页面，不是 MoviePilot 连接配置页，也不是手动转存入口。

使用前准备

  • 先完成“工具箱 → MoviePilot”的地址、API Key 和账号配置，并确认连接测试成功。
  • 确认 CineChill 容器能访问 MoviePilot 和需要读取的站点服务；浏览器能打开不代表容器网络一定可达。
  • 首次运行只选择一个站点或一个小范围媒体条件，先确认结果再扩大筛选范围。

页面区域怎么看

  • 顶部统计：用于快速判断站点数量、监控状态、资源候选和任务结果，不等于所有下载任务都已完成。
  • 站点状态：关注已启用、连接失败、暂时跳过等状态；单个站点失败时不要立即重置全部配置。
  • 资源列表：用于查看候选资源的站点、质量、编码、季集和匹配结果；严格匹配时，缺少关键元数据的条目可能被过滤。
  • 处理状态：下载、上传、整理和跳过属于不同阶段，排障时应结合系统运行日志确认实际停在哪一步。

推荐操作顺序

  1. 打开站点管理，先确认统计卡片和站点状态已加载。
  2. 检查站点筛选、质量条件、媒体类型和季集匹配条件。
  3. 先查看候选列表，核对标题、年份、季集、分辨率和站点来源。
  4. 只对一条候选执行后续处理，观察任务日志和整理记录。
  5. 确认下载、上传、识别和入库均正常后，再开启定时或批量处理。

常见问题与回滚

  • 站点全部失败：先检查 MoviePilot 连接、代理、DNS 和容器网络，再判断是否是单站点问题。
  • 候选很多但没有自动处理：核对严格匹配、质量筛选、媒体库状态和季集信息，不要直接降低所有保护条件。
  • 重复下载或重复入库：立即暂停自动任务，检查订阅、站点监控和整理记录，确认去重条件后再恢复。
  • 误触发处理：停止当前任务并保留日志；已经提交到外部服务的任务不会因为关闭页面自动回滚，需要到对应任务页单独取消。

开启站点监控并触发一次下载

站点管理是 MoviePilot 下载链路的监控和筛选入口。MoviePilot 连接配置必须先在“工具箱 → MoviePilot”完成，站点管理本身不负责保存 API Key。

  1. 先确认 MoviePilot 连接、代理、站点和下载器在外部服务中可用。
  2. 打开站点管理，确认站点状态和统计卡片已加载。
  3. 设置媒体类型、质量、分辨率、季集和严格匹配条件。
  4. 在候选列表核对标题、年份、季集、来源和质量，只选择一条候选触发处理。
  5. 提交后不要重复点击；分别到 MoviePilot 任务、系统运行日志和整理记录核对下一阶段。

“发现、下载、入库”不是一个状态

  • 发现：站点有候选资源。
  • 下载：MoviePilot 已创建任务，文件仍可能没有完成。
  • 硬链接：下载完成后，MP 按配置把文件链接到 CineChill 监控目录。
  • 整理入库：CineChill 识别、重命名、移动 / 写入 STRM 并等待 Emby 刷新。

出现重复下载：先暂停监控或相关自动任务，检查订阅记录、候选去重条件和整理记录，确认原因后再恢复。

按阶段排查：站点监控与触发下载

站点全部连接失败

  1. 先去“工具箱 → MoviePilot”测试连接；如果连接失败，不要在站点列表里逐个重置。
  2. 连接正常但站点失败，检查代理、DNS、站点登录状态和 MoviePilot 外部日志，先判断是单站点还是全局网络。
  3. 修复一个站点后只刷新一次，确认站点状态恢复，再恢复定时监控。

候选资源为空

  1. 检查媒体类型、质量、分辨率、季集和严格匹配条件；一次只放宽一个条件。
  2. 确认媒体标题、年份和 TMDB ID 识别正确；识别错误时回发现推荐或订阅详情修正，不要盲目降低筛选。
  3. 确认站点确实返回候选后，再保存监控设置；候选为空不等于下载器故障。

触发后重复下载或没有后续硬链接

  1. 立即暂停监控和重复订阅，记录标题、候选、时间和 MoviePilot 任务 ID。
  2. 下载成功但没有硬链接，转查 MoviePilot 的下载目录、硬链接规则和同文件系统条件。
  3. 硬链接出现但 CineChill 没有任务，转查 115 秒传的监听目录映射并手动扫描一次。
