控制台 / 真实库

“真实库 RSS”是订阅任务管理页：可以生成或填写 RSS 地址、预览解析结果、保存 Cron 任务、手动运行、启停和删除。运行结果会记录解析数量、TMDB 匹配、待处理条目、硬链接和上次同步时间。

适用场景与准备工作

  • 为自有合法授权媒体建立周期性 RSS 订阅，并把结果交给后续媒体库整理。
  • 准备一个可访问的 RSS 地址，或使用页面提供的“生成来源 / 内置榜单”。内置榜单的字段由后端返回，不要猜写不存在的参数。
  • 先确认 115、Emby 和可选的 MoviePilot 连接正常；RSS 本身可预览，不代表后续下载或入库一定成功。

按页面顺序操作

  1. 从左侧控制台直接进入“真实库”，点击“添加订阅”。
  2. 填写“订阅名称”，再选择“生成来源”。选择内置榜单后，按页面出现的字段填写并点击“生成并填入”；也可以直接在 RSS 地址框中每行填写一个地址。
  3. 检查 RSS 地址预览内容，确认解析条目、展示数量和 TMDB 匹配信息基本符合预期。
  4. 填写“Cron 表达式”，选择“电影”或“电视剧”。已有 RSS 地址时，内容类型会锁定；需要切换类型，先清空地址或新建任务。
  5. 仅在确实需要时打开“同步真实库缺失到 MP”。它会把缺失、缺集和连载未完结条目同步为 MoviePilot 订阅，先用少量任务验证。
  6. 点击“保存”。任务卡片出现后，可按需“运行、启用 / 停用、编辑、删除”。手动运行后页面会自动刷新运行结果，最长等待窗口约为 5 分钟；超时只代表页面停止轮询，不代表后台一定停止。

字段与任务指标

  • RSS 地址：支持多行地址；任务会把地址解析成条目，预览区展示可识别的标题、年份、类型和 TMDB ID。
  • Cron：控制后台调度周期。保存前先确认表达式适合本机负载，避免高频请求。
  • 榜单数量：最近一次任务解析到的 RSS 条目数；解析进度是 TMDB 已匹配 / 总条目。
  • 待处理：尚未完成识别的条目数量；不是“下载失败”数量。
  • 硬链接数：最近运行中产生或记录的硬链接数量；它不是文件总数。
  • 同步 MP：打开后会把真实库缺失同步到 MP；关闭只影响后续同步，不会自动删除已存在的 MP 记录。

首次小范围验证

  1. 只配置一个 RSS 地址、一个低频 Cron，并关闭“同步真实库缺失到 MP”。
  2. 先点“预览”，核对条目数量和标题；预览报“部分源失败”时，不要直接保存成高频任务。
  3. 保存后手动“运行”，确认任务卡片的上次同步、解析进度和硬链接数发生合理变化。
  4. 确认无误后，再增加地址、打开缺失同步或调整周期。

常见问题、风险与回滚

  • 预览无条目：检查地址可达性、源格式和字段；先换一个已确认可用的自有源，不要凭空修改 URL。
  • 运行后一直没有变化：查看任务卡片和系统运行日志；页面轮询超时后重新进入页面读取后台状态。
  • 删除任务：删除时会询问是否同时删除硬链接文件和 Emby 媒体库；选择“只删订阅”可保留文件和媒体库，选择前必须确认。
  • 误开 MP 同步：先停用任务，再到 MoviePilot 订阅管理核对并取消不需要的订阅。
  • 不要把 RSS 任务指向成品库后直接开启破坏性删除；先保留现有文件和备份，再调整任务。

真实库 RSS 如何接到订阅和下载

真实库 RSS 负责定时读取条目并判断缺失；它可以选择把缺失条目同步给 MoviePilot，但不会代替 MoviePilot 下载，也不会代替 CineChill 整理入库。

  1. 先确认 Emby、115 和 MoviePilot 已测试成功。
  2. 添加一个 RSS 地址或使用页面提供的生成来源，先点击预览核对标题、年份、类型和 TMDB 匹配。
  3. 第一次关闭“同步真实库缺失到 MP”，保存低频任务并手动运行。
  4. 确认预览、解析进度和任务状态正常后，再开启缺失同步。
  5. 同步到 MP 后，回订阅系统确认订阅记录；后续下载、硬链接和整理按主流程继续。

指标不要混淆

  • 解析数量：RSS 读到了多少条目。
  • TMDB 匹配：有多少条目找到了媒体身份。
  • 待处理：还没有完成识别或后续处理的条目，不等于下载失败。
  • 硬链接数：最近任务记录到的硬链接数量，不等于媒体库文件总数。

删除前注意：任务删除可能询问是否连硬链接和 Emby 媒体一起删除；第一次选择只删订阅或停用任务，先保留文件。

按指标排查：真实库 RSS

RSS 抓取失败或解析数量为 0

  1. 先点击页面预览，记录 HTTP 状态、最后运行时间和错误摘要；不要直接打开同步缺失。
  2. 超时/连接失败查 RSS 地址、DNS、代理和容器网络；200 但解析为 0 查返回内容是否真的是 RSS/XML。
  3. 只保留一个 RSS 来源重新预览，确认解析数量大于 0 后再合并其他来源。

解析有条目但 TMDB 匹配为 0

  1. 展开一条条目核对标题、年份、媒体类型和季集；不要只看总数量。
  2. 测试 TMDB 配置和代理；标题异常时先人工确认一条，不要批量修改原始条目。
  3. 匹配成功后再保存低频任务，观察“解析数量、匹配数量、待处理数量”是否按预期变化。

同步到 MoviePilot 后没有订阅或重复订阅

  1. 先确认 MoviePilot 配置测试成功，再确认“同步缺失到 MP”开关已经保存。
  2. 回订阅系统查 TMDB ID、季集和创建时间；记录已存在时不要重复点击同步。
  3. 重复任务先暂停 RSS 或订阅任务，保留一条正确记录，再检查 Cron 频率和去重条件。
